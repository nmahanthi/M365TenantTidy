# M365TenantTidy

Read-only Windows tool that reviews a Microsoft 365 tenant for unused or wasted licences and produces cost-saving reports. It runs on your own computer and sends no data to the publisher; its only network calls go to Microsoft sign-in and Microsoft Graph.

Download the installer from the [Releases](../../releases) page.

Silent install: `M365TenantTidy-Setup-<version>.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART`
